# Kodee Runner

This is a demo game for the Kotlin 15 years celebration. Help Kodee run and jump over obstacles!

Built with Kotlin Multiplatform and Compose Multiplatform for Android, iOS, Desktop and Web.

## Controls

- **Jump / start:** Space or tap
- **Pause / resume:** P or the Pause button

## Running

- Android: `./gradlew :androidApp:assembleDebug`
- Desktop: `./gradlew :desktopApp:run`
- Web: `./gradlew :webApp:wasmJsBrowserDevelopmentRun`
- iOS: open [/iosApp](./iosApp) in Xcode and run it from there.
